# Abdullah Ahmad — Next-Level Portfolio (Static Hosting)

This portfolio is designed for static hosting. It does **not** require Vercel, Node.js, a server, or a paid subscription to deploy.

## What's included
- `index.html`, `style.css`, `script.js`
- Your portrait: `abdullah.jpg`
- Animated green/blue liquid-style ambient background
- Responsive cinematic layout, services, experience and enquiry form

## Publish from your phone for free
1. Download and extract this ZIP on your phone (Files / My Files app).
2. Open Cloudflare Dashboard in Chrome and sign in: https://dash.cloudflare.com/
3. Go to **Workers & Pages** → **Create** → **Pages** → **Upload assets** (wording can vary).
4. Name the project and upload the extracted site files/folder. Make sure `index.html`, `style.css`, `script.js`, and `abdullah.jpg` are at the top level, not hidden inside another nested folder.
5. Deploy. Cloudflare will give you a public `pages.dev` link.

## Enquiry form (no server required)
The form uses FormSubmit, which forwards form submissions to `abdullahahmad7085@gmail.com`.
1. After publishing, submit one test enquiry from the website.
2. Check the inbox for `abdullahahmad7085@gmail.com` for FormSubmit's activation/confirmation email.
3. Open that email and confirm activation. Then submit another test to check delivery.
4. If the service asks you to confirm a redirect URL or if the confirmation page is not ideal, the form still sends through FormSubmit; the redirect is optional and can be adjusted in `index.html`.

Note: FormSubmit is a third-party service. Its first-use email activation is required and delivery depends on that service's availability/spam controls. Do not add private API keys to public website files.
